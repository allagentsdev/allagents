---
title: Installation
description: How to install AllAgents.
---

AllAgents can be installed globally using npm or run directly with npx.

When using npm or npx, Node.js 22 or newer is required.

## Using npm (recommended)

```bash
npm install -g allagents
```

## Using npx

Run AllAgents without installing:

```bash
npx allagents
```

:::note
HTTP MCP servers also work when setup is run through `npx`. Generated client
configs invoke a pinned AllAgents version through `npx`, which reuses npm's
package cache after the first launch.
:::

## Using bun

```bash
bun install -g allagents
```

## Standalone binaries

Every [release](https://github.com/allagentsdev/allagents/releases/latest)
attaches a self-contained executable per platform, so AllAgents can run without
Node.js or Bun. Download the archive for your platform — `linux-x64`,
`linux-arm64`, `darwin-x64`, `darwin-arm64`, or `windows-x64` — and check it
against the `SHA256SUMS` file attached to the same release.

```bash
# Linux x64, replacing <version> with the release version
curl -LO https://github.com/allagentsdev/allagents/releases/download/v<version>/allagents-<version>-linux-x64.tar.gz
tar -xzf allagents-<version>-linux-x64.tar.gz
./allagents --version
```

Each archive contains the `allagents` executable (or `allagents.exe` on
Windows) and `THIRD_PARTY_NOTICES.txt`. `allagents self update` manages npm and
bun installations; to update a standalone binary, extract a newer archive over
it.

## Verify Installation

After installation, verify it's working:

```bash
allagents --version
```

## Updating

AllAgents automatically checks for new versions in the background when you use the interactive TUI. If an update is available, you'll see a notice on startup.

To update manually:

```bash
allagents self update
```

This auto-detects whether you installed with npm or bun and uses the same package manager. You can also force a specific one with `--npm` or `--bun`.

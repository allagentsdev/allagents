title: Marketplaces
description: Using and creating plugin marketplaces.
---

Marketplaces are collections of plugins hosted on GitHub.

## Using Marketplaces

```bash
allagents plugin marketplace add anthropics/claude-plugins-official
allagents plugin marketplace list
```

### Project Scope

Register and update a remote marketplace for the current project:

```bash
allagents plugin marketplace add owner/repo --scope project
allagents plugin install demo@repo --scope project --client codex --yes
allagents plugin update --scope project
```

Project registrations use a cache owned by that project's registry. A user registration with the same name keeps its own cache; updating one scope leaves the other scope's cache and installed files unchanged. Project plugins can also use a user marketplace when the project has no matching registration.

### Branch Selection

To register a marketplace from a non-default branch, use a full GitHub URL with the branch path or the `--branch` flag. A custom `--name` is required for non-default branches:

```bash
# Full GitHub URL with branch
allagents plugin marketplace add https://github.com/owner/repo/tree/feat/v2 --name repo-v2

# Shorthand with --branch flag
allagents plugin marketplace add owner/repo --branch feat/v2 --name repo-v2
```

The bare repo name (e.g., `repo`) is reserved for the default branch. Updates automatically pull the correct branch.

## Creating a Marketplace

```
my-marketplace/
├── plugins/
│   ├── code-review/
│   └── debugging/
└── README.md
```
